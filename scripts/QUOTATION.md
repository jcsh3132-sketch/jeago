# 견적서 운영 연결

- `/quotation`은 로그인 회원의 이름·연락처·이메일을 서버에서 지정합니다.
- `QUOTATION_ENGINE=server`에서 Vercel이 원본 PDF 템플릿과 굴림 글꼴로 직접 PDF, 모바일 PNG 미리보기를 생성합니다. 회사 PC·Excel·로컬 서버는 필요하지 않습니다.
- `QUOTATION_SMTP_USER`, `QUOTATION_SMTP_PASSWORD`는 Vercel의 비밀 환경변수입니다. 브라우저, Git, 작업 큐에 비밀번호를 저장하지 않습니다.
- 메일은 원래의 로고·계정별 명함·홈페이지 서명을 유지합니다. 제목은 견적서 제목이며 첨부파일명도 같습니다.
- 회원별 작업을 격리하고 서버에서 동기적으로 완료한 뒤 결과만 저장합니다. 요청 ID를 재사용해 중복 메일 발송을 방지합니다. 결과 불명확 시 자동으로 재발송하지 않습니다.
- 로그인 사용자의 30분 지난 임시 결과는 요청 시 정리합니다. 메일 내용은 DB에 남기지 않습니다.
- `GET /api/quotation?verifyMail=1`은 로그인 후 SMTP 인증을 확인하며 실제 메일을 발송하지 않습니다. 서버 인스턴스별 60초 동안 결과를 재사용합니다.
- 기존 PC 작업자는 운영 서버 엔진에서 사용하는 작업을 가져가지 못합니다. 장애 롤백은 엔진 환경변수를 이전 값으로 변경한 후 재배포합니다.
